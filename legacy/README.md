# レガシー版（HTML / CSS / JavaScript）

これは、React + Spring Boot + PostgreSQL構成に移行する前に作成した、学習用の最初のバージョンです。

- `index.html` / `style.css` / `script.js`：HTML/CSS/JavaScriptの基礎学習用に作成した、`localStorage`でデータを保存するシングルページアプリ
- `mock/`：画面イメージ確認用に作成したプロトタイプ（現在は本体と同じ内容）

## 使い方

`index.html` をブラウザで直接開けば、今でも動作します（サーバー不要）。

## 位置づけ

このフォルダの内容は、今後更新しません。DOM操作・イベント処理・配列操作といったJavaScriptの基礎を学んだ記録として、そのまま残しています。現在開発中の本体（React + Spring Boot + PostgreSQL構成）は、プロジェクトルート直下の`frontend/`・`backend/`フォルダにあります。
