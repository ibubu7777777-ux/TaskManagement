# タスク管理アプリ（Trello風）

Trelloのように、カードを列（未着手・作業中・完了）に並べてタスクを管理できる、シンプルなタスク管理アプリです。
HTML・CSS・JavaScriptのみで作られており、サーバーやビルドツールは不要です。

## 使い方

1. このフォルダにある `index.html` をダブルクリックしてブラウザで開く
2. それだけで動作します（インストールや環境構築は不要です）

## 主な機能

- 未着手・作業中・完了の3つの列でタスクを管理
- カードの新規作成
- カードのテキスト編集（カードをクリックすると編集できます）
- カードの削除（カード右側の×ボタン）
- ドラッグ&ドロップによるカードの移動・並び替え
- ブラウザの`localStorage`にデータを自動保存（リロードしても内容が消えません）

## 使用技術

- HTML5
- CSS3（Flexbox）
- JavaScript（DOM操作、HTML5 Drag and Drop API、Web Storage API）

ビルドツールやフレームワークは使用していません。

## ファイル構成

```
index.html   ページの骨組み
style.css    見た目のスタイル
script.js    データ管理・描画・イベント処理などのロジック
```
