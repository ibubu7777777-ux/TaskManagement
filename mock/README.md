# 画面イメージ確認用プロトタイプ

これは、[docs/画面設計.md](../docs/画面設計.md) に書いたワイヤーフレーム・操作フローをもとに作成した、画面イメージ確認用のモック（プロトタイプ）です。

## 目的

- 実装を進める前に、画面レイアウトと操作感をブラウザで実際に触って確認・認識合わせするためのもの
- データベースやバックエンドとの連携は行わず、HTML・CSS・JavaScriptのみで完結する

## 使い方

`index.html` をブラウザで直接開いてください（サーバー起動不要）。

## 確認ポイント

- `docs/画面設計.md` のワイヤーフレーム通りに、未着手・作業中・完了の3列が横並びで表示されるか
- `docs/画面設計.md` の操作フロー図通りに、カードの追加・編集・削除・ドラッグ&ドロップ移動ができるか

## 注意

このフォルダの内容は確認用のスナップショットです。今後プロジェクトルート直下のアプリをバックエンド（Node.js + Express + SQLite）連携に改修していく予定ですが、このモックはシンプルな見た目確認用として現状のまま維持します。
